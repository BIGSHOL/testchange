# 그림 문항 벤치마크 (figbench)

DeepSeek(이미지 불가) 해설의 **그림 의존 문항 정확도**를 참값 대조로 채점하는 자산.
프롬프트(`core/ocr_engine.FIGURE_DESC_PROMPT`·`EXAM_OCR_PROMPT` 그림/표 규칙,
`core/solution_generator._SYSTEM_PROMPT` 그림 중재 규칙)를 바꿀 때마다 여기로 회귀 확인.

## 참값 (전부 수학 검산 — ⚠️ 학생 체크는 정답이 아님, 참고만)

| 파일 | 내용 | 근거 |
|---|---|---|
| `catalog_multi.json` | 운암중 중3 25-2-기말 그림 문항 18 + 학남고 공수2 1 — 정답·발문·선택지·그림 참값 서술 | 문항별 수학 검산(세션 비전) |
| `wang_answers.json` | 왕선중 중3 25-2-기말 전 23문항 정답 + 풀이 근거 | 수학 검산(좌표 검산 포함). #9 는 학생 답(④)이 틀리고 검산 ③이 정답인 실례 |
| 오성중 | `corpus/[오성중][3][25-2-기말] (원본)/ocr/p*_merged.json` 의 `answer` | 사람 작업본 대조(21/21 검증됨) |

## 하네스

`figbench.py` — [그림 크롭 → /api/figure-desc 서술 → /api/solution 풀이 → 채점].
서술·풀이는 배포 엔드포인트(생산 경로와 동일) 사용, 캐시(`figbench_cache/`)로 반복 비용 절감.
경로 상수(CORPUS·SITE·CODE)는 파일 상단 참조. 원본 PDF 는
`N:\개인\기출\기출작업\198, 199차\` (로컬 미러 `D:\기출`).
