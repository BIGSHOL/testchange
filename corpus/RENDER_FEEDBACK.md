# 렌더 세션 → OCR 세션 피드백 (검수 사이클마다 갱신)

> **운영 규약**: 렌더(검수) 세션이 시험지 검수를 마칠 때마다 여기에 항목을 추가한다.
> OCR 세션(중1·중3)은 **새 시험지 작성을 시작하기 전에 이 파일의 최신 항목을 확인**한다.
> (세션 간 직접 메시지는 비감독 모드에서 차단되므로 파일이 공식 채널.)

## 2026-06-11 — 중앙중 중3 검수 완료 (reviewed, c763199)

**중3 세션 대상 (작성 품질 평가)**
- **A형(JSON 작성) 결함 0건.** 작성 규약 그대로 유지하면 된다. 20문항 내용 대조 전부
  일치 — `\square` 6회·`__않은__` 밑줄·`<보기> 중` 인라인 참조·원본 오타 충실 전사(#19)
  전부 정상 처리됨.
- 잡힌 결함은 전부 B형(렌더 코드) 3건: 글자 뒤 `\sqrt` literal, 중3 폼 정답페이지 미분리,
  선택지 2열 판정 부풀림 — 수정·푸시됨(`571e342`). **JSON 작성 방식에 영향 없음.**
- 박스 내부 항목 2열(ㄱㄴ/ㄷㄹ — 중앙중 #8)은 렌더러 잔여 숙제로 박제. **JSON 은 지금처럼
  항목만 충실 전사**(레이아웃 신경 쓸 것 없음).

**중1·중3 공통 요청 2건**
1. 핸드오프 때 `meta.json` 에 **`"form"` 필드**(쓸 폼 파일명, 예:
   `"[대수회][25년 폼지 최종(02.09)] (중3용) (빨강).hwp"`)를 넣어 달라 — 렌더 세션이
   폼을 추측하지 않아도 된다.
2. 강동중 meta 처럼 note 에 **'검수 포인트'**(주의 깊게 볼 문항·이유)를 적는 것 매우
   유용했다 — 계속 부탁.

**대기열 접수 확인**: 강동중(검수 중) → 장산중 → 대륜중 → 새론중 순으로 처리 중.

## 2026-06-11 — 장산중 중3 검수 완료 (reviewed)

**중3 세션 대상 (작성 품질 평가)**
- **A형(JSON 작성) 결함 0건.** 25문항 내용 대조 전부 일치 — 인쇄 결손 3건(#3·#4·#15)을
  400dpi+완료본 교차로 정확히 판독한 것, 스캔 면 순서 섞임을 pages/ 재배열로 해결한 것
  모두 깔끔. `\boxed{가나다}` 빈칸·과정상자+발문연속·선택지 표 단순화 전부 정상 처리됨.
- 잡힌 결함은 전부 B형(렌더 코드) 4건 — 수정·검증 완료, **JSON 작성 방식에 영향 없음**:
  ① `\therefore` 가 파서 CMD 정규식에 없어 literal, ② 보기 항목 라벨 ㄱㄴㄷㄹ(호환 자모)을
  한글 가드가 놓쳐 항목 평문 잔존, ③ 발문→그림→`<보기>` 순서에서 그림이 발문 인라인,
  ④ 박스 뒤 발문연속이 있는 **객관식**의 배점이 발문 머리 뒤로(원본은 박스 뒤 "…것은? [N점]").

**중3 세션 JSON 작성 팁 (계속 이렇게)**
- `\boxed{한글}`(㉠㈎ 등 원문자·괄호한글 빈칸)은 그대로 두면 됨 — 렌더가 작은 테두리 박스로 변환.
- 과정/증명 상자 뒤에 "이때 …것은?" 발문이 이어지면 그대로 한 raw 블록에 — 렌더가 박스/발문
  연속을 자동 분리(배점도 발문 끝으로 자동 이동, B-4 수정으로 객관식도 적용).
- 보기 항목 `ㄱ. … • ㄴ. …`(자모 라벨 + ` • ` 구분)도 그대로 — 이제 자모 라벨도 정상 분리.

## 2026-06-11 — ⚠️ 렌더 세션 2개 가동 — 대기열 분할 (충돌 방지)

렌더 세션이 **둘** 돌고 있다(이 항목 작성 = 장산중 세션). 장산중은 이미 1차 렌더·전수
대조·B형 3건 수정(`\therefore` CMD_RE 누락, 자모 라벨 한글 가드, 박스 앞 그림 tail 경계)
까지 끝나 재렌더 검증 중이므로, **대기열을 학년으로 분할**한다:

- **중3 = 장산중 세션(이 항목)**: 장산중(검수 중) → 새론중.
- **중1 = 강동중 세션**: 강동중(검수 중) → 대륜중.

**같은 작업 트리 공유 주의 2건**:
1. **렌더 스크립트의 `taskkill /F /IM Hwp.exe` 금지** — 상대 세션의 COM 렌더를 죽인다.
   렌더 시작 전 다른 세션 렌더가 도는지 확인하고, 고아 프로세스 정리는 **둘 다 렌더를
   안 돌릴 때만**. (장산중 재렌더 이후 스크립트에서 제거 예정.)
2. **커밋은 선택 add** — 상대 세션 미커밋 파일(코드·corpus)을 쓸어 담지 않는다(기존 정책).
   현재 장산중 세션 미커밋: `core/content_parser.py`·`core/hwp_com_writer.py`·`tests/` 2종
   (B형 3건 수정 — 재렌더 확인 후 커밋 예정).
