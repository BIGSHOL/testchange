# 시험지 한글화 — 사용설명서

수학 시험지 PDF를 한글(HWP) 문서(.hwpx)로 자동 변환하는 프로그램입니다.

## 1. 준비물
- **한글(HWP)** 설치 (수식을 한글에 직접 입력하려면 필수). 미설치 시 내장 변환기로 자동 전환됩니다.
- **API 키** (글자·수식 인식에 사용) — 아래 둘 중 **하나 이상**:
  - **Gemini API 키** (기본·권장 — 저렴하고 빠릅니다). https://aistudio.google.com 에서 발급.
  - **Anthropic(Claude) API 키** (선택). https://console.anthropic.com 에서 발급.

## 2. 최초 설정 — API 키 입력
프로그램 폴더의 **`config.json`** 을 메모장으로 열어 키를 채웁니다. **기본은 Gemini로 인식**하므로
`GEMINI_API_KEY` 만 있어도 됩니다.

```json
{
  "GEMINI_API_KEY": "AIza........",
  "ANTHROPIC_API_KEY": "",
  "OCR_BACKEND": "auto",
  "OUTPUT_DIR": ""
}
```

- `OUTPUT_DIR` 을 비워두면 프로그램 폴더 아래 `output` 에 저장됩니다.
- 프로그램 안의 설정 화면에서 키를 입력하면 자동으로 `config.json` 에 저장됩니다.
- `OCR_BACKEND` 는 보통 `auto`(자동) 그대로 두면 됩니다(아래 4번 참고).

## 3. 사용 순서
1. **`시험지한글화.exe`** 실행
2. 변환할 시험지 **PDF 선택** (또는 파일 영역에 드래그)
3. (선택) **폼지·OCR 엔진** 드롭다운 확인 — 보통 기본값(자동) 그대로 두면 됩니다.
4. **변환 시작** 클릭
5. 진행바가 끝나면 결과 `.hwpx` 파일이 출력 폴더에 생성됩니다.

## 4. 동작 방식
- PDF → 이미지 → OCR(글자·수식 인식) → 구조 분석 → 한글(HWP) 직접 입력 → `.hwpx` 저장
- **OCR 엔진(자동)**: 시험지 상태에 맞춰 페이지마다 가장 적합한 방식을 자동으로 고릅니다
  (선명한 페이지는 빠른 인식, 스캔·저품질 페이지는 정밀 인식). 특정 방식으로 고정하고 싶으면
  드롭다운에서 직접 선택할 수 있습니다.
- **폼지(자동)**: 파일명의 학년·과목을 감지해 맞는 양식을 고릅니다. 규칙과 안 맞으면 양식 없이
  기본 서식으로 그대로 변환합니다(원하면 드롭다운에서 양식을 직접 선택).
- **그림(도형/그래프)**: 그림 자리에 안내 박스("※ 그림 자리 — 원본에서 캡처해 붙여넣으세요")가
  들어갑니다. 원본에서 해당 부분을 캡처해 붙여넣으세요.
- 수식은 한글이 직접 렌더링하므로 크기가 정확합니다. 한글 미설치 시 내장 생성기로 자동 폴백합니다.

## 5. 자주 묻는 질문
- **"보안 모듈 허용" 팝업이 떠요** → 정상입니다. 한글 파일 입출력 보안 절차이며 자동 처리됩니다.
- **변환이 느려요** → 첫 페이지는 한글 구동 시간이 포함됩니다.
- **수식이 글자로 나와요** → 해당 수식 인식 실패 케이스입니다. 원본 PDF 화질을 높이거나 재시도하세요.
- **그림이 안 들어가요** → 정상입니다(그림 자리에 안내 박스). 원본에서 직접 캡처해 붙여넣으세요.

## 6. 문제 해결
- 변환 중 오류가 나면 프로그램이 한글을 자동 종료합니다. 작업관리자에 `Hwp.exe` 가 남아있으면 수동 종료 후 재시도하세요.
- `config.json` 에 API 키(Gemini 또는 Anthropic)가 하나도 없으면 OCR 단계에서 오류가 납니다.
