# 시험지 한글화 — 사용설명서

수학 시험지 PDF를 한글(HWP) 문서(.hwpx)로 자동 변환하는 프로그램입니다.

## 1. 준비물
- **한글(HWP)** 설치 (수식을 한글에 직접 입력하려면 필수). 미설치 시 내장 변환기로 자동 전환됩니다.
- **Anthropic API 키** (OCR에 사용). https://console.anthropic.com 에서 발급.

## 2. 최초 설정 — API 키 입력
프로그램 폴더의 **`config.json`** 을 메모장으로 열어 `ANTHROPIC_API_KEY` 값을 채웁니다.

```json
{
  "ANTHROPIC_API_KEY": "sk-ant-api03-........",
  "OUTPUT_DIR": "",
  "CLAUDE_MODEL": "claude-sonnet-4-6"
}
```

- `OUTPUT_DIR` 을 비워두면 프로그램 폴더 아래 `output` 에 저장됩니다.
- 프로그램 안의 설정 화면에서 키를 입력하면 자동으로 `config.json` 에 저장됩니다.

## 3. 사용 순서
1. **`시험지한글화.exe`** 실행
2. 변환할 시험지 **PDF 선택** (또는 파일 영역에 드래그)
3. **변환 시작** 클릭
4. 진행바가 끝나면 결과 `.hwpx` 파일이 출력 폴더에 생성됩니다.

## 4. 동작 방식
- PDF → 이미지 → Claude OCR → 구조 분석 → 한글(HWP) 직접 입력 → `.hwpx` 저장
- 수식은 한글이 직접 렌더링하므로 크기가 정확합니다(수식 11pt, 본문 10pt 고정).
- 한글이 설치되어 있지 않으면 내장 XML 생성기로 자동 폴백합니다(수식 크기 근사).

## 5. 자주 묻는 질문
- **"보안 모듈 허용" 팝업이 떠요** → 정상입니다. 한글 파일 입출력 보안 절차이며 자동 처리됩니다.
- **변환이 느려요** → 첫 페이지는 한글 구동 시간이 포함됩니다. 수식이 많아도 페이지당 약 10초 수준입니다.
- **수식이 글자로 나와요** → 해당 수식 인식 실패 케이스입니다. 원본 PDF 화질을 높이거나 재시도하세요.

## 6. 문제 해결
- 변환 중 오류가 나면 프로그램이 한글을 자동 종료합니다. 작업관리자에 `Hwp.exe` 가 남아있으면 수동 종료 후 재시도하세요.
- `config.json` 의 API 키가 비어 있으면 OCR 단계에서 오류가 납니다.
