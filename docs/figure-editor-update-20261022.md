# 공용 도형 엔진 업데이트 · 2026-10-22

공유 편집기 정본: `BIGSHOL/math-figure-editor`의 `129207f`.
화살표 생성·편집 변경 정본은 `69d134b`이며, todays-math에서는 `406615bf8`로 먼저 적용했다.

이 저장소는 Python 네이티브 엔진이다. 기존 모눈·그림 조각·원근 직각·단위 글자 변경에 이어, 이번에는 생성 화살표 메타데이터를 반영했다. React 편집기의 수식편집기·틀 넓히기·PNG 출력 변경은 공용 웹 편집기 쪽 변경이며, 네이티브 GUI의 입력·HWP 저장 흐름은 유지한다. 웹앱 전용 관리자·사용 통계·IP 차단·서버 최근 작업을 이 저장소에 복사하지 않는다.

## 반영 범위

- `scripts/figure/graph_scene.py`: 직선 화살표의 선+촉을 `data-arrow="end"` 그룹으로 출력한다. 이 저장소의 기존 그래프 어댑터를 유지하며 해당 출력 부분만 수정했다.
- `scripts/figure/elementary.py`: 오른쪽·위·아래 연결 화살표도 같은 표시를 붙인다.
- `scripts/figure/figure_assets.py`: 양방향 치수 화살표는 `data-arrow="both"`, 라벨은 그룹 밖에 둔다.
- `core/figure_quality.py`: `g`의 `data-arrow`만 허용하며 값은 `end/both`로 제한한다. marker나 외부 SVG 참조는 새로 허용하지 않는다.
- 네이티브 배포 버전 `0.1.27`.

공유 편집기는 이 표시를 읽어 화살표를 하나의 편집 요소로 변환한다. 과거 저장 SVG는 다시 쓰지 않았으며, 표시가 없는 임의 선+삼각형은 추정해 합치지 않는다. 별도 곡선 지시선 표현은 이번 범위 밖이다.

## 검증

- 기존 엔진 시험 5파일 108개 통과.
- 새 `tests/test_editor_arrow_metadata.py` 12개 통과: 연결·양방향·그래프 표시, 라벨 분리, 잘못된 메타데이터 거부, 이전 실제 출력 7종과 260px resvg 렌더의 픽셀 차이 0.
- 픽셀 기준은 `19a4bde`에서 만든 `tests/fixtures/editor_arrow_baselines.json`이다. git이 없는 환경에서도 같은 기준으로 검사한다.
- 전체 corpus 검사에는 기존 문제가 있다. 검사 스크립트는 11개 파일/167개 그림을 기대하지만 현재 추적 corpus는 14개 파일/204개 그림이다. 별도 실제 구조·픽셀 검사 결과 183개 통과, 21개는 기존 겹침/halo/숨은 rect/텍스트 수 제한에 걸렸다. 이번 변경은 이 corpus나 픽셀 검수 규칙을 수정하지 않았다.
- 왕선중 corpus와 OCR 등 기존 dirty 및 작업 파일을 보존했고 이 커밋에는 포함하지 않는다.

새 표시의 보안·출력 회귀는 통과했지만, 기존 corpus 전체 품질 게이트를 통과했다고 보고하지 않는다. 상세 웹 검수·공용 UI 적용 안내는 정본 저장소의 `docs/reviews/2026-10-22-webapp.md`와 `docs/export/todays-math/UPDATE-2026-10-22.md`에 있다.
