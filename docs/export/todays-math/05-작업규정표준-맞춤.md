| 표준 | 입력 | 이전 출력 | 이후 출력 |
|---|---|---|---|
| #38 확률 P 정자, 사건 이탤릭 | `P(A\cap B)` | `P(A SMALLINTER B)` | `rm P it (A SMALLINTER B)` |
| #44 평균·분산 정자 | `E(X)=27` | `E(X)=27` | `rm E it (X)=27` |
| (오탐 없음) 다항식·점 | `P(x)`·`P(2,3)` | 그대로 | 그대로(괄호 안이 소문자·숫자면 안 건드림) |
| #49 삼각함수 각 이탤릭 + 1/4칸 | `\tan A` | `tan rm A` 계열 | ``tan`A`` |

| #37 여집합 대문자 C | `(A\cup B)^c` | `(A SMALLUNION B)^{c}` | `(A SMALLUNION B)^{C}` (집합 뒤만 — `5^c`·`(x+1)^c` 그대로) |
| #54 행렬 | `\begin{pmatrix}2&3\\4&5\end{pmatrix}` | `PMATRIX {2 & 3 # 4 & 5}` | ``LEFT ( `` MATRIX {2 ~~& 3 # 4 ~~& 5} `` RIGHT )`` |

- 행렬은 렌더 비교로 정했다: 표준 예 ``LEFT ( ``2~~3``#``4~~5 RIGHT )`` 와 가장 가까우면서 음수·식 항목도 열이
  맞는 것이 `MATRIX` + 열 사이 `~~`. PMATRIX 는 괄호에 붙고 열이 좁아 3×3 이 "207135 82" 처럼 붙어 읽혔다.
- ⚠️ 확률 P 를 정자로 바꾸면 **표 셀 스크립트가 `rm P it (X=x)` 가 된다** — 표 종류를 `P(X` 로 판정하던 코드가
  있으면 같이 고칠 것(우리는 확률분포표 음영 판정이 그랬다).

### 1-1. 집합 중괄호 = 자동 크기 ``LEFT { … RIGHT }``(#36 예시 `A=left{1,~2,~3 right}`)
짝이 맞는 맨 ``\{…\}`` 는 전부 ``\left\{…\right\}`` 로 올린다. ⚠️ HWP 에서 ``LEFT "{"``(따옴표 리터럴)는 깨지고
**맨 중괄호** ``LEFT { … RIGHT }`` 만 된다(우리 2026-07-31 실측).

## 3. 같이 드러난 함정 ○ (한글 HWPX 를 직접 다루면 꼭 볼 것)

- ⭐⭐ **XML 에서 문단 글자 수를 바꾸면 그 문단의 `<hp:linesegarray>` 를 지워라.** 두 줄로 접힌 문단은 줄마다 시작
  위치(`textpos`)를 들고 있다. 앞에 글자를 넣으면 그 위치가 수식 컨트롤 한가운데를 가리키고, 한글은 **그 지점에서
  읽기를 멈추고 나머지 문서를 통째로 버린다**(미주 22개 → 12개, 실측). 줄 정보 없는 문단은 한글이 다시 잰다.
- ⭐ `<hh:tabItem pos>` 는 **HWPUNIT 의 2배** 값이다. **홀수면 한글이 그 탭 설정을 통째로 버린다**.
- ⭐ 한글은 문서를 열고 저장해도 **글자만 있는 문단의 `<hp:tab width>` 를 다시 재지 않는다**(수식이 든 문단은 잰다).
  탭 설정을 XML 로 바꿨으면 한글 안에서 그 문단을 한 번 건드려야(글자 넣었다 지우기) 폭이 맞는다.
- ⭐ 열 맞춤 탭은 **쪽·단 배치를 재기 전에** 적용한다. 기본 탭 상태의 값 줄은 길게 접혀 높이가 부풀고, 그 높이로
  배치를 정하면 다음 문항(보기 상자)이 단 경계에서 갈라졌다(성광중 #15 실측).
- ⭐ 넘친 배점을 "지우고 다시 쓰면" 새 글이 문단 기본 글꼴로 바뀌었다 → 지우지 말고 **그 런 앞에서 줄만 나눠**
  통째로 옮긴다(글자모양·수식 보존, 범위 삭제도 없어짐).
